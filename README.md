# Hotel Home - Booking and Admin System

ASP.NET MVC hotel platform with guest-facing booking flows and a staff admin area for rooms, rates, and operations.

## Overview
Full hotel website + management suite: search/book rooms, manage property content, and support operational reporting.

## Key Features
- Room search, details, and reservation flow
- Admin portal for rooms, rates, amenities, and users
- Booking / check-in oriented screens
- Operational reports (arrival/departure style views)
- Payment integration hooks
- Entity Framework + SQL Server persistence

## Tech Stack
- **Backend:** ASP.NET MVC (C#), .NET Framework 4.7.2
- **Frontend:** Razor views, JavaScript, jQuery, Bootstrap
- **ORM:** Entity Framework
- **Database:** Microsoft SQL Server
- **Solution:** `HotelWebsite.sln`

## Getting Started
1. Open the solution in Visual Studio
2. Point `Web.config` connection strings to your database
3. Restore packages and build
4. Run under IIS Express
